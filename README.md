# ClipoTxt Official Website

Official landing page and interactive web experience for **ClipoTxt** — the local-first on-device screenshot-to-text OCR utility for Windows 10 & 11 by Bharath Thommandru.

## Features
- **100% Client-Side**: Pure HTML5, CSS3, and modern ES6 JavaScript. Zero backend dependencies.
- **Interactive 3D Companion**: Draggable companion with physics and intelligent knowledge assistant.
- **WebGL Particle Orb & Strands**: Hardware-accelerated canvas animations with fluid scroll physics.
- **Client-Side Security Gates**: Built-in anti-inspection and asset protection.

## Setup & Deployment
Open `index.html` directly in any web browser, or host on GitHub Pages, Netlify, or Vercel.
